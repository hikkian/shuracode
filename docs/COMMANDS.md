## Shura (terminal) / Shura (в терминале)

| Command | What it does | Что делает | Key | From |
|---|---|---|---|---|
| `shura` | Start ShuraCode (starts the gateway and warms the model). | Запустить ShuraCode (поднимает шлюз и прогревает модель). |  | shura |
| `shura check / report` | Check what fits your hardware, and make a report to share. | Проверить, что подходит твоему железу, и собрать отчёт, чтобы им поделиться. |  | shura |
| `shura install / uninstall / start / stop` | Install or remove the engine and model, start or stop it (the universal installer). | Установить или удалить движок и модель, запустить или остановить (универсальный установщик). |  | shura |
| `shura logs` | Follow the gateway log. | Смотреть журнал шлюза. |  | shura |
| `shura off` | Switch the AI off (it will not load until `shura on`). | Выключить ИИ (не загрузится до `shura on`). |  | shura |
| `shura on` | Switch the AI back on. | Снова включить ИИ. |  | shura |
| `shura pause / resume` | Game mode by hand: park the model, or bring it back (only when game mode is enabled). | Режим игры вручную: поставить модель на паузу или вернуть (только если режим игры включён). |  | shura |
| `shura restart` | Restart the gateway. | Перезапустить шлюз. |  | shura |
| `shura status` | Model state, memory, VRAM. | Состояние модели, памяти и видеопамяти. |  | shura |
| `shura unload` | Free RAM and VRAM right away. | Сразу освободить RAM и видеопамять. |  | shura |
| `shura warm` | Load the model now. | Загрузить модель сейчас. |  | shura |
